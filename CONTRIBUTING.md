# Contributing

Thanks for your interest in contributing to `chow`.

## GitHub Issues

If you find a bug, have a feature request, or want to suggest an improvement, please open a GitHub issue.

When opening an issue, please try to include:

- A clear and descriptive title
- A short summary of the problem or request
- Steps to reproduce the issue, if applicable
- Expected behavior and actual behavior
- Relevant logs, error messages, or sample input
- Version information and environment details when helpful

Before opening a new issue, please check existing issues to avoid duplicates.

## Pull Requests

Pull requests are welcome.

To help reviews go smoothly:

- Keep changes focused and limited in scope
- Include a clear description of what changed and why
- Reference the related issue when applicable
- Update documentation if behavior or usage changes
- Add or update tests when relevant

Please make sure your changes build and any relevant tests pass before submitting a pull request.

## Review Process

Maintainers may ask for changes, clarification, or additional tests before merging.

By submitting a contribution, you agree that your work may be distributed under the project's license.
