# Security Policy

## Reporting a Vulnerability

If you believe you have found a security issue in this project, please report it through GitHub Issues.

When opening a security-related issue, please include:

- A clear summary of the issue
- The affected component or file, if known
- Steps to reproduce the problem
- The potential impact
- Any suggested remediation, if available

If the issue may expose users to immediate risk, please avoid posting sensitive exploit details publicly in the initial report. Instead, provide a brief summary and request maintainer follow-up through the repository.

## Security Updates

Security fixes will be handled through the normal project review and pull request process unless maintainers indicate otherwise.

## Supported Versions

This project does not currently publish a separate supported versions policy. Please use the latest version available when reporting security issues.
